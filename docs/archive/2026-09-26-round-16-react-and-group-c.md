## 1. C6 подробно: два разных предпросмотра

| | Админский мини-превью (ваше описание) | C6-site из старого ТЗ |
| --- | --- | --- |
| Что видит админ | Демо-кнопка/уведомление прямо на экране настроек; поменял надпись — надпись сменилась; навёл курсор — показался hover-фон | Реальную страницу магазина с временными (несохранёнными) настройками |
| Где | Внутри `RVN → Сравнение`, панель редактора стилей | Отдельная вкладка с token-ссылкой на витрину |
| Сложность | Средняя: React перерисовывает демо из состояния формы | Высокая: подписанный token, TTL, capability, `no-store`, защита от кэша и утечки другим посетителям |
| Решение | **Оставляем**: часть редактора стилей, 0.5.0 (база) → 1.1 (полный) | **Убираем**: overkill для вашей задачи |

Почему site preview — лишнее: мини-превью закрывает 95% потребности («как выглядит кнопка»), а token-механизм добавляет поверхность для багов безопасности ради редкого сценария. Если когда-нибудь понадобится «посмотреть в контексте темы» — это решается обычной черновой страницей, без token.

Записано: `SPEC §12` (явный пункт «Dropped»), `DECISIONS` (строка C6), `STATUS` (в составе 1.1 — только мини-превью).

## 2. C7 подробно: какие шаблоны

Речь **не** о внешнем виде таблицы. Два разных понятия:

1. **Раскладка таблицы** (ваш вопрос): «подписи строкой сверху» (текущая, уже в коде) vs «липкая левая колонка» (второй шаблон). Это фича продукта, второй шаблон запланирован в **1.3+**. Ничего не меняем.
2. **Переопределение шаблонов в теме (C7)**: механизм для разработчиков тем. Тема копирует PHP-файл разметки плагина в свою папку и правит его; плагин использует копию вместо своей. Как `woocommerce/single-product.php` в теме.

Почему убираем C7:
- устаревшие копии в темах не получают security-фиксы;
- вечная поддержка совместимости копий;
- наша таблица в основном рисуется JS (`table.js` + REST), поэтому PHP-копии шаблонов дадут мало пользы;
- публичные хуки/фильтры + стабильные CSS-классы покрывают реальные нужды кастомизации.

Записано: `SPEC §12` (Dropped с причиной), `DECISIONS` (строка C7). Вернём только по реальному запросу разработчика темы.
