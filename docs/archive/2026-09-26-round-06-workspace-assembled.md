## 1. Сессия, раунд и сброс песочницы

### Определения

| Термин | Что это |
| --- | --- |
| **Сессия (session)** | Весь чат от открытия до закрытия. Одна сессия = одна вкладка диалога. |
| **Раунд (round)** | Одно ваше сообщение + мой ответ целиком. Внутри одного моего ответа может быть много tool-шагов (чтение файлов, команды) — это всё один раунд. |
| **Сброс песочницы** | Пересоздание машины: стирается всё системное (установленные пакеты, базы данных, фоновые процессы, `/tmp`), остаются только файлы проекта. |

### Доказательства (замеры в начале этого раунда)

| Что проверялось | В прошлом раунде | Сейчас |
| --- | --- | --- |
| Uptime системы | — | **30 секунд** (машина только что создана) |
| `php`, `mariadb`, `wp`, `composer` | установлены и работали | **отсутствуют** |
| Тестовые сайты в `/tmp` | были | `/tmp` пуст |
| Файлы проекта (`docs/`, `src/`, `AGENTS.md`) | — | **на месте** |

Вывод: сброс происходит **между раундами**, а не только между чатами. В старом чате писали «сброс перед каждой сессией», но наблюдали то же самое («стенд из прошлого раунда исчез») — просто называли это сессией. Точная формулировка: *перед каждым раундом надо исходить из того, что системы нет, а файлы есть*.

### Что это значит для стендов

Ваша интуиция верна полностью: после каждого раунда стенды исчезают, и следующий раунд начинает с нуля. Отсюда пять следствий, которые уже закреплены в правилах:

1. **Каждый раунд со стендом — самодостаточен:** `doctor` → минимальная установка → подъём → проверки → `down` → запись результата в отчёт. Нельзя «продолжить стенд» из прошлого раунда — его нет.
2. **Установка должна быть минимальной**, потому что платим за неё каждый раз: PHP 8.1 + 8.3 (а не 4 версии), только Chromium (а не 3 браузера).
3. **Один уровень проверок на раунд** (ваше решение): уровень 0 — один раунд, уровень 1 — следующий. Полный цикл собирается из 3–4 раундов.
4. **В конце раунда гасить демоны** (`stand.sh down`, остановка MariaDB, проверка `pgrep` пустая). Формально сброс всё равно всё сотрёт, но «засыпать в покое» важно: прошлая песочница, скорее всего, погибла именно на снимке, снятом посреди фоновой установки.
5. **Память между раундами — только файлы:** таблица прогресса в `docs/test-reports/<версия>.md` (какой уровень на каком стенде пройден) и запись в `docs/LOG.md`.

### Сколько стоит один раунд (замеры из этой песочницы)

| Раунд | Что ставится | Ориентир |
| --- | --- | --- |
| Уровень 0 (статика) | PHP CLI 8.1 и 8.3, Composer + PHPCS/WPCS/PHPStan, WP-CLI | ~2–3 мин |
| Уровень 1 (сборка) | то же + MariaDB + WordPress + WooCommerce + Chromium | ~4–6 мин |
| Уровень 2 (совместимость) | как уровень 1, но стенд `min` и/или другой браузер | ~4–6 мин |
