# RVN Compare — Текущий ответ

## Приёмка 0.4.1 закрыта, планы согласованы, рабочая область полностью обновлена

1. **Приёмка 0.4.1:** Все 5 пунктов ручного тестирования на Storefront 4.6.2 (кавычки шорткода, миниатюры, стрелки слайдера, стабильность вкладок, 5 колонок) приняты и закрыты. Версия 0.4.1 стабильна.
2. **Консультация по пропорциям изображений:**
   - Согласовано добавление настроек `image_ratio` (`1:1` по умолчанию, `3:4`, `4:3`, `16:9`, `auto`) и `image_fit` (`contain` по умолчанию, `cover`).
   - Реализация на чистом CSS (`aspect-ratio`, `object-fit`), без дублирования размеров в медиабиблиотеке. Войдёт в 0.5.0 вместе с визуальными настройками таблицы.
3. **Ширина экрана (`window.innerWidth`):** Подтверждено — `innerWidth` в реальном времени реагирует на боковую панель DevTools (F12), зум и поворот экрана.
4. **Структура раздела «Поддержка» и справки:**
   - 0.5.0: Встроенная контекстная помощь (`add_help_tab`) в настройках плагина + структура FAQ.
   - 0.6.0: Модульный экран «RVN → Поддержка» с общей вкладкой линейки RVN и расширяемыми вкладками через `Core::add_support_tab()` для каждого активного плагина.
5. **Все документы рабочей области пересозданы:**
   - Созданы и согласованы: `AGENTS.md`, `README.md`, `docs/STATUS.md`, `docs/HANDOFF.md`, `docs/SPEC.md`, `docs/DECISIONS.md`, `docs/ARCHITECTURE.md`, `docs/TESTING.md`, `docs/LOG.md`.
   - Документы переведены на английский язык для экономии токенов и универсальности, а ответы и чек-листы остаются на русском.
   - Минимальные требования повышены до WordPress 6.6+ и WooCommerce 9.0+. Упоминания ZIP исключены.
