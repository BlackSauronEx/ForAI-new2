## Found and fixed

1. **WPCS on the generated `settings.asset.php`** (3 errors + 1 warning:
   dotted filename vs `NotHyphenatedLowercase`, array formatting). Generated
   files should not be linted: added `*/assets/admin/*` to the PHPCS
   exclude list in `wp-dev/phpcs.xml.dist` (sources live in
   `wp-dev/admin-ui/src/` and are reviewed there). Rerun green.
2. **Flaky frontend check** (`front main`: “button became active” +
   “notification shown” failed with empty details while the follow-up checks —
   toast text, saved list, counter, reload state — all passed). Cause: a
   click-to-assertion race in the test, unrelated to this round (no frontend
   code changed). Isolated rerun: 17/17; full level 1 rerun: 12/12. The red
   intermediate artifacts were deleted; the green runs are archived.
